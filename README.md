# OSTRELYA WEB STUDIO

Marketing site for OSTRELYA — a web studio building modern, mobile-first, monthly-payment websites for small businesses across Croatia, Bosnia, Serbia and beyond.

**Live:** https://ostrelya.com/

---

## Stack

- Static HTML / CSS / JS (no framework, no build step for the HR site)
- Vanilla CSS with a design-token system (`css/styles.css`)
- GSAP 3 + ScrollTrigger (CDN, `defer`) for animations
- Custom i18n engine (`js/i18n.js`) — English is the inline HTML default; Croatian is swapped client-side
- Self-hosted/`en/` English build generated from the source pages by `build.js`

## Build the English site

Prerequisite: [Node.js](https://nodejs.org) (tested on Node 18+).

```bash
cd ostrelya-site-shader-m
node build.js
```

This regenerates everything under `en/` from the root source pages, applying the
translation dictionary in `build.js`. **Do not edit files under `en/` directly** — they
are overwritten on the next build. Edit the root source page + the `DICT` in `build.js`, then rebuild.

### Adding / updating a translation

1. Open `build.js` and edit the relevant key under `const DICT = { ... }` (or add a new key).
2. Add a matching `data-i18n="key"` attribute to the element in the source HTML.
3. If the Croatian client-side dictionary needs it too, add the key under `HR` in `js/i18n.js`.
4. Run `node build.js`.

## Analytics (Umami, self-hosted)

A placeholder Umami script is added to each page head. Before going live, replace the
placeholders in `index.html` (and re-run `node build.js` to propagate to `en/`):

```html
<script defer src="https://YOUR-UMAMI-INSTANCE/script.js" data-website-id="YOUR-WEBSITE-ID"></script>
```

You must also allow the instance in the CSP `script-src` (the site's CSP is a meta tag in
each page's `<head>`). Pings go back to the same origin, so `connect-src 'self'` already covers them.

## Deployment

- Canonical host is **https://ostrelya.com/**.
- **`dist/` is the deploy snapshot** — it is managed separately and is *not* regenerated by
  `build.js`. After changing source pages, rebuild `en/`, then rebuild/refresh `dist/` and deploy it.
- `cloudflare-redirect-to-com.ps1` creates 301 redirects from `ostrelya.info` and `ostrelya.org`
  (path-for-path) to `.com`. See the script header for token requirements and usage.

---

## Cookie consent / GDPR

The cookie banner (`#cookieBanner`, driven by `js/main.js`) offers **Accept** and **Decline**.
A choice is stored in `localStorage` under `ostrelya_cookie_consent`. No non-essential scripts
are currently loaded, but the banner is the hook point to gate the Umami analytics snippet behind
an explicit "Accept" if you want stricter consent handling.

## Notes / conventions

- The `shader-bg.js` WebGL background was removed as dead code (never referenced by any page).
  If you want the animated background back, recreate the canvas element and re-add the script.
- Orphaned root PNGs (removed) were unreferenced generated assets. Keep them out of the repo.
- Color palette is cool slate/blue/purple (see `:root` tokens in `css/styles.css`);
  the PWA manifest `theme_color`/`background_color` is `#f8fafc` to match.
